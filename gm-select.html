README

Interface: tabbed modules, chosen so the engineer can jump between filtering, target definition, scaling, visual QA, and export without losing settings.

Algorithms: SDOF elastic pseudo-acceleration spectra via Newmark average acceleration (β=1/4, γ=1/2); RotD00/50/100 from 1° horizontal rotations; Arias intensity, Husid D5–95, Housner intensity and CAV; logarithmic least-squares scaling; exact-combination best-fit-N for N≤8 and greedy forward-selection otherwise.

Code spectra: EC8 Type 1/2, ASCE 7-22 general form, and IS 1893:2016 standard spectral shape. Parameters are exposed in the UI. This is an engineering aid, not a certified reproduction of SeismoSoft.

Adding a code: extend makeCodeTarget() with a new spectral-ordinate function, then wire the parameter panel and option list.

GM-Select is an offline, client-side engineering aid. Sample records are synthetic/illustrative and are never presented as real earthquakes.
